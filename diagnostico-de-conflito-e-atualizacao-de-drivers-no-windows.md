# Atualização de Drivers no Windows

- **Autor(a):** Giovani Do Nascimento Fernandes
- **Categoria:** Diagnóstico de Conflito e Atualização de Drivers no Windows

> **Alerta de Segurança:** Fazer backup do sistema antes de atualizar os drivers


## 1. Sintoma e Diagnóstico Inicial

O computador precisa ser atualizado constatemente para evitar conflitos, para evitar falhas ou para trazer mais segurança ao usuário. Por exemplo, os altos falantes não estão saindo o som, o driver de aúdio pode estar corrompido ou em conflito. Para corrigir tal erro, é necessário atualizar o driver de som.


## 2. Ferramentas e Recursos Necessários

- **Hardware / Bancada:** Não se aplica.
- **Software / Utilitário:** Criar um ponto de restauração.


## 3. Procedimento de Solução (Passo a Passo)

1. Procurar o driver no site do fabricante ou site de busca.
2. Criar um ponto de restauração.
3. Instalar o driver.
4. Verificar se a instalação deu certo.

- Tire um print da tela após a finalização da instalação do driver.
